# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please use this repository's GitHub Security tab to report a vulnerability
privately. Do not open a public issue for credential exposure, unsafe command
injection, microphone capture, terminal input injection, or private-data
retention concerns.

Include the affected version, macOS version, reproduction steps, and impact.
Do not attach API keys, recordings, transcripts, personalized trigger profiles,
or other private data. You can expect an initial response within seven days.
